# 🚀 CEMS Quick Start - One-Click Launch

## Desktop App Launcher (No Browser Opening Needed)

### Windows Users - Easiest Way ⭐

**Simply double-click this file:**
```
LAUNCH_CEMS.bat
```

That's it! It will:
✅ Start the Flask server automatically  
✅ Open your default browser to the app  
✅ Show welcome info with demo accounts  

### Python Users - Alternative Way

Run this command in terminal:
```bash
python launch_cems.py
```

## 🆘 Troubleshooting

**Issue:** "Python not found"
**Fix:** Install Python 3.8+ from python.org

**Issue:** "Virtual environment not found"
**Fix:** Run: `python -m venv .venv`

**Issue:** "Module not found"
**Fix:** Run: `.venv\Scripts\pip install -r requirements.txt`
